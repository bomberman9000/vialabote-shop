# cutout/ — намеренно пусто

`CUTOUT` для всех 11 SKU = **MANUAL_REVIEW**.

Почему cutout'ы не созданы автоматически:

- У 4 из 11 упаковок **прозрачный колпачок** (hyaluron-8in1, retinal, multi3, resveratrol-c), у остальных — полупрозрачное тёмное стекло с бликами. Автоматическая маска (u2net/rembg и т.п.) на белом фоне либо съедает прозрачный пластик, либо оставляет белый ореол — это «красивый фальшивый продукт», которого правила проекта запрещают.
- Для витрины cutout не нужен: packshot-серия снята на белом в одной студии, после flat-field (`enhanced/`) белый фон на сцене `.vl-stage` (`mix-blend-mode: multiply`) превращается в тон сцены — результат визуально равен cutout'у без риска для этикетки и колпачка.

Когда понадобятся (campaign, композиции на цветном фоне): ручная маска в Photoshop/Affinity с отдельным слоем для прозрачного колпачка, проверка 1:1 по этикетке. Результат класть сюда как `<sku>-cutout.png` (RGBA) и отметить в `PRODUCT-MEDIA-MANIFEST.md`.
