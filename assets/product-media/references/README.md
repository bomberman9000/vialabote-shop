# References — принципы, не ассеты

Только ссылки и анализ. Чужие фотографии, CSS, HTML, тексты и раскладки не копируются и не скачиваются.

## TYPOLOGY — https://www.typology.com/

What we borrow:
- whitespace: много воздуха вокруг каждого товара, сетка «дышит»;
- product hierarchy: единая «сцена» для всех флаконов → ассортимент читается как одна линейка (у нас: `.vl-stage` + нормализованные packshot);
- ingredient storytelling: активный компонент как первый уровень навигации (у нас: «Ключевые компоненты» на PDP, поиск по составу).

## AUGUSTINUS BADER — https://augustinusbader.com/

What we borrow:
- luxury science: спокойная научная подача без «аптечности» — точные формулировки, без громких обещаний;
- PDP hierarchy: название → польза → цена/CTA → компоненты → применение; большая галерея с липким позиционированием;
- editorial/product balance: packshot для покупки, редакционные снимки — для истории бренда (у нас: блок «О бренде»).

## AESOP — https://www.aesop.com/

What we borrow:
- restraint: минимум декоративных элементов, тонкие разделители вместо карточек-коробок (у нас: строки PDP через hairline-границы);
- typography: крупные спокойные заголовки, мелкий капс-«eyebrow» с разрядкой над секциями;
- subtle motion: короткие мягкие переходы, ничего не «прыгает» (у нас: reveal 16 px / 640 ms, hover-scale 1.025, `prefers-reduced-motion`).

## RHODE — https://www.rhodeskin.com/

What we borrow:
- emotional beauty imagery: тёплая «кожная» фотография как эмоциональный вход (у нас: hero V2);
- tactile presentation: фактура, свет, капли — ощущение текстуры продукта без изображения упаковки (у нас: процедурные текстуры карточек потребностей с плёночным зерном).
